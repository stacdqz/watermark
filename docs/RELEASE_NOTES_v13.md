# DCT-Pro Research Workbench v13 for Windows — Release Notes

## 程序名称

图像数字水印嵌入与鲁棒检测提取系统 v13（DCT-Pro Research Workbench v13）

## 程序用途

用于图像数字水印嵌入、盲提取与鲁棒性评测的 Windows 桌面实验工作台。用户可以在同一套流程中完成水印嵌入、对抗攻击仿真、提取验证与报告导出，用于教学演示、实验复现与传播场景下的水印可检测性验证。

## 版本与标签

- Release 标签：`v13.0`
- 程序标题：图像数字水印嵌入与鲁棒检测提取系统 v13

## 支持系统

- Windows 10 / Windows 11 桌面端
- 已在本机 Windows 环境完成启动核验（进程正常启动并可响应）

## 运行环境

- 独立打包的可执行文件，运行**不需要安装 Python**；
- 不需要额外安装 PyQt6 / OpenCV / NumPy 等 Python 依赖。

## 算法模式

程序内置四种水印模式：

- `LSB`：空间域基线方案（对压缩、裁剪较脆弱）；
- `DCT`：经典 DCT 中频系数比较方案；
- `Visible`：显性水印，用于肉眼可见的视觉对比（通常不进行盲提取）；
- `DCT-Pro`：本项目探索的分块 DCT 增强方案。

## 主要功能

- 水印嵌入（含嵌入强度 / 显水印透明度调节、拖拽加载、点击放大预览）；
- 水印提取（与嵌入算法一致时进行盲提取，输出检测报告与失败原因提示）；
- 图像质量指标：PSNR / SSIM，以及亮度通道差异热图；
- 单项攻击测试：JPEG 压缩、缩放、噪声、亮度变化、旋转、滤波、裁剪/遮挡等；
- 批量攻击测试：攻击集合统一执行、逐项结果与总体成功率；
- 组合攻击流水线：多攻击原语组成多步骤破坏序列；
- 三算法对比：同一攻击集合下对比 LSB / DCT / DCT-Pro；
- 报告导出：Markdown 文本报告与图片版报告；
- 后台线程处理、进度更新与错误捕获。

## 基本使用步骤

1. 下载 `v13_ex.exe` 并双击运行；
2. "嵌入"页：加载或拖拽图片 → 选择算法 → 输入水印文本 → 设置强度 → 点击"嵌入水印"；
3. 查看 PSNR / SSIM，可点击"差异热图"观察修改分布，"保存结果"导出水印图像；
4. "提取"页：加载水印图或受攻击图像 → 选择对应算法 → 点击"提取"；
5. "攻击测试"页：执行单项/批量/组合攻击，或运行三算法对比，必要时导出报告。

## 已知限制

- 研究与演示项目，非商业产品；
- 嵌入与提取算法必须一致，否则可能无法正确提取；
- 图像尺寸过小会限制可嵌入的数据量；
- 鲁棒性取决于参数、图像内容与攻击类型；
- 显水印（Visible）用于视觉对比，行为与隐水印不同；
- 程序未进行商业代码签名。
