# DCT-Pro 研究成果与攻击测试结果

> 本页汇总 DCT-Pro 数字图像水印研究最新一轮批量实验（2026-08-03）的实验设置、量化指标、攻击测试结果与可视化图表。所有图片与 CSV 均由实验工具直接导出，可下载复查。

## 1. 实验总览

| 项目 | 说明 |
|---|---|
| 水印内容 | `DCT_PRO_COPYRIGHT`（短文本） |
| 测试图像 | 500 张（COCO val2017 子集，每项攻击 n=500） |
| 对比配置 | 6 个 Preset：Base / JND / Tile_only / Tile / Sync / Full |
| 攻击类型 | 30 种（JPEG 压缩、缩放、噪声、亮度、滤波、锐化、色彩抖动、真实裁剪、遮挡裁剪、旋转、组合攻击） |
| 记录规模 | 109,021 条逐图明细 |
| 评价指标 | PSNR / SSIM、严格检测率（Strict DR）、BER、运行耗时（ms） |

## 2. 核心结论

- **全增强方案（Full）整体严格检测率 76.39%**，较 Base（28.01%）提升约 48 个百分点；平均 BER 从 0.509 降至 0.232。
- **模块贡献**：Tile_only 单独即可达到 59.43%，说明局部封装 + 冗余嵌入是鲁棒性的主要来源；Sync（同步头）在真实裁剪与旋转场景下提供额外收益；Full 综合最强。
- **强项**：闭环、JPEG Q90、高斯噪声、锐化、色彩抖动、缩放 200%、黑色遮挡裁剪全部 100% 通过；JPEG Q70 99.6%、Q50 99.0%、Q30 91.9%。
- **短板**：真实随机裁剪（0.61%）、组合攻击 上裁 30% + JPEG Q30（0%）、旋转 5°（0%）、真实中心裁剪 60%（31.98%）仍会失败，是后续优化重点。
- **代价**：Full 平均耗时 281.9 ms（P95 849.5 ms），图像质量 PSNR 39.46 dB / SSIM 0.9758，为六种配置中最低。
